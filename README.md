### 🚀 Flagship Project: StreamPanel (https://github.com/zibirik/streamdeck)

> Turn your Android tablet into a premium control deck for your Windows PC.  
> *Stream · Work · Study · Gaming · Automation · Smart Home — all from one glassy dashboard.*

![Release (https://img.shields.io/github/v/release/zibirik/streamdeck?include_prereleases&style=flat-square&color=8b5cf6)](https://github.com/zibirik/streamdeck/releases/latest)
![CI (https://img.shields.io/github/actions/workflow/status/zibirik/streamdeck/ci.yml?style=flat-square&label=CI)](https://github.com/zibirik/streamdeck/actions/workflows/ci.yml)
![Android (https://img.shields.io/badge/Android-Jetpack_Compose-3DDC84?style=flat-square&logo=android&logoColor=white)](https://github.com/zibirik/streamdeck)
![Windows (https://img.shields.io/badge/Server-.NET_8_Minimal_API-0078D4?style=flat-square&logo=windows&logoColor=white)](https://github.com/zibirik/streamdeck)

A production-ready, two-part system engineered from scratch:
- 📱 Android Client (Kotlin, Jetpack Compose, Material 3, Hilt, Room, DataStore, Ktor): Custom grids up to 12×12, drag & drop layout, live PC hardware telemetry widgets, OBS Control Room, and Counter-Strike 2 Game State Integration (GSI) HUD.
- 🖥 Windows Server (.NET 8, ASP.NET Core Minimal APIs): Self-contained companion daemon handling Windows API hooks, window snapping, hotkeys, process management, and custom WebSocket protocol (:17820) with PIN authentication and brute-force IP lockout.
- 🔌 Ecosystem Integrations: OBS WebSocket 5.x, CS2 GSI, MQTT, Home Assistant, Philips Hue, Spotify, and automated UI screenshot testing (ShellScreenshotTest) via GitHub Actions CI/CD.
