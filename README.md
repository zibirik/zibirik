## 🔭 What I do

- **Mobile & desktop:** Android apps with Jetpack Compose, Material 3, Hilt, Room, DataStore, Ktor; Windows tools and system integrations (Win32 API, hotkeys, window management).
- **Backend & protocols:** ASP.NET Core Minimal APIs, WebSockets, gRPC / Protobuf, MQTT, custom client–server protocols with auth and rate limiting.
- **AI & automation:** local ASR (Whisper), OCR pipelines, LLM agents with task planning, voice interfaces, TTS.
- **Engineering practices:** SOLID, design patterns, automated tests, CI/CD with GitHub Actions, Docker, Git workflow.
